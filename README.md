# NORTEX — Herramientas en Monterrey

> Plataforma web industrial, moderna y de alto impacto para **NORTEX**, especializada en la comercialización y distribución de herramientas profesionales para construcción, industria y mantenimiento en Monterrey, su área metropolitana y toda la República Mexicana.

---

## 🚀 Tecnologías

- **Framework:** [React 19](https://react.dev/) + [Vite](https://vitejs.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Estilos:** Vanilla CSS con Design Tokens Industriales (Colores carbón, acero, acento naranja forja `#FF5500`)
- **Iconografía:** [Lucide React](https://lucide.dev/)
- **Tipografía:** Google Fonts (*Barlow Condensed*, *Rajdhani*, *Inter*)
- **SEO & Datos Estructurados:** Schema.org (`LocalBusiness`, `Organization`, `Product`, `BreadcrumbList`, `FAQPage`), `sitemap.xml` y `robots.txt`

---

## 📦 Características Principales

1. **Header Sticky & Buscador Predictivo:** Búsqueda en vivo por Nombre, SKU, Marca, Modelo y Categoría.
2. **Hero de Alto Impacto:** Identidad norteña con imágenes industriales de grado pesado.
3. **Catálogo de 8 Categorías:** Herramientas manuales, eléctricas, para construcción, industriales, accesorios, seguridad (EPP), medición y ferretería.
4. **Sistema de Cotización (RFQ):** Drawer interactivo para añadir herramientas, modificar cantidades y exportar la lista de cotización directamente hacia **WhatsApp** o mediante formulario B2B.
5. **SEO Local Monterrey:** Optimizado para Monterrey, Apodaca, San Nicolás, Guadalupe, Santa Catarina, Escobedo, García y San Pedro.
6. **Centro de Herramientas:** Blog técnico con guías de selección de maquinaria y criterios de ingeniería.
7. **Páginas Canónicas:**
   - `/` — Inicio
   - `/herramientas` — Catálogo general con filtros
   - `/categoria/[slug]` — Landing especializada de cada categoría
   - `/producto/[slug]` — Ficha técnica, tabla de especificaciones y galería
   - `/marcas` — Directorio de líneas asociadas
   - `/nosotros` — Visión y valores de marca
   - `/cotizacion` — Formulario formal de cotización
   - `/contacto` — Canales comerciales
   - `/blog` — Centro de herramientas

## 💻 Instalación y Uso Local

```bash
# 1. Clonar el repositorio
git clone https://github.com/Arcano3Ai/NORTEX.git
cd NORTEX

# 2. Instalar dependencias
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev

# 4. Construir para producción
npm run build
```
